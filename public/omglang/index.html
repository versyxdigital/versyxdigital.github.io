A small language, built end to end.

OMG is a programming language made for fun, and for learning how languages get put together. It has the usual things: variables, math, strings, lists, dictionaries, loops, functions and files. Nothing flashy. What makes it worth a look is that you can follow it all the way down, to a compiler written in OMG itself.

# the language

Everything a language needs, and not much more

Six keywords get you most of the way: alloc, emit, if, loop, proc and return. Each card opens the matching lesson, where every example can be edited and run.

Variables

alloc introduces a name, := changes it. A typo is an error, never a silent new variable.

alloc count := 0
count := count + 1
emit count          # 1

Functions and closures

Functions are values. An inner function remembers the variables around it.

proc make_adder(n) {
    proc add(x) { return x + n }
    return add
}
emit make_adder(5)(10)   # 15

Lists and dictionaries

Indexing, negative indexes, slices, and dictionaries with dot or bracket access.

alloc xs := [10, 20, 30]
emit xs[-1]         # 30
alloc p := {name: "Chris"}
emit p.name         # Chris

One loop

There is a single looping construct. It runs while its condition holds, and break leaves it.

alloc n := 1
loop n <= 100 {
    n := n * 2
}
emit n              # 128

Errors you can catch

Uncaught errors print a traceback with line numbers. try and except recover.

try {
    emit [1, 2, 3][99]
} except err {
    emit "oops: " + err
}

Files and modules

Split a program across files with import, and read and write files as text or bytes.

import "mathlib.omg" as math
emit math.square(5)     # 25
emit read_file("notes.txt")
# how it works

Follow one line all the way down

Running a program takes four steps. Here is what each one makes of emit 1 + 2 * 3. These are the real outputs, not a diagram of the idea.

00 source

Text

A program starts as characters in a file.

emit 1 + 2 * 3
01 lexer

Tokens

The lexer groups characters into words and symbols.

EMIT NUM PLUS NUM STAR NUM
02 parser

Syntax tree

The parser works out what belongs to what: * binds tighter than +.

emit └ add ├ 1 └ mul ├ 2 └ 3
03 compiler

Bytecode

The compiler flattens the tree into simple instructions.

PushInt(1) PushInt(2) PushInt(3) Mul Add Emit
04 virtual machine

Result

The VM carries the instructions out on a stack.

7

The compiler is written in OMG. A first compiler, written in Rust, exists to get things started. The real one is about 2,700 lines of OMG, and it compiles itself. Both must produce identical bytecode, byte for byte, and a test checks that on every change. This site goes one step further: the code running in your browser is that OMG compiler and an OMG virtual machine, turned into JavaScript by a backend that is also written in OMG.

# written in OMG

Small, but it does real work

The best test of a language is writing things in it. All of these live in the repository.

  • its own compiler Lexer, parser and bytecode generator. It compiles every program you run, including itself.
  • a virtual machine A second VM, in OMG, that runs the same bytecode as the Rust one. It powers this site.
  • two backends One turns bytecode into C for small native programs, the other into JavaScript. With the compiler and the VM they make up a single omg command, which builds itself.
  • a SQL database omgdb: a paged file format on disk, a hand-written SQL parser and an interactive shell.
  • terminal games Snake, Pong, Tetris and a small roguelike, plus a spinning ASCII donut.
  • Unix tools wc, grep, sort, uniq, head, tail, a hex dump, base64 and a JSON formatter.
  • a text editor A terminal editor with undo and redo, written against raw keyboard input.
  • a tiny web stack A Markdown to HTML converter, a static site generator and an HTTP server.
# on your machine

Run it locally

You need Rust 1.80 or newer and nothing else. The runtime builds on Linux, macOS and Windows. Run omg with no arguments for an interactive prompt.

View the source on GitHub 
# build the runtime
git clone https://github.com/sentrychris/omglang
cd omglang
cargo build --release --manifest-path runtime/Cargo.toml

# run a program
runtime/target/release/omg examples/hello_world.omg
